🔴 Segurança — 2 problemas críticos

GET /propostas   → todas as propostas

2. SQL Injection em 19 pontos (crítico)

utils/database.py tem f-strings direto em queries SQL — exemplos reais encontrados:

# Linha 2338
f"SELECT usuario_id FROM propostas WHERE id = {proposta_id_int}"

# Linha 4087  
f"...WHERE proposta_id = {proposta_id} AND tipo = '{tipo}'"

# Linha 4094
f"UPDATE acrescimos_proposta SET status_pagamento = '{status}'..."
O campo tipo e status vêm de input — isso é injeção potencial. Precisa trocar por parâmetros %s com binding.

🟡 Segurança — 2 pontos de atenção
